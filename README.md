# 広告運用ダッシュボード

Meta・Google・Amazon等の広告媒体のCSVを読み込んで、パフォーマンスを可視化するツールです。

## 使い方

1. `広告運用ダッシュボード.html` をダウンロードしてブラウザで開く
2. 「CSVを読み込む」ボタンから各媒体のCSVファイルをアップロード
3. 集計・グラフが自動で表示される

インターネット接続があれば、インストール不要でそのまま動作します。

## ⚠️ データの共有について（今後の課題）

現在、読み込んだデータは**自分のブラウザ上にのみ存在**します。

- ページを閉じるとデータは消える
- 他のメンバーと同じデータを見るには、各自がCSVを読み込む必要がある

### 理想の運用フロー（未実装）

```
担当者がCSVをGoogle Driveにアップ
  → ダッシュボードが自動でデータを取得
  → 全員が同じデータをリアルタイムで確認
```

この仕組みを実現するには **Google Apps Script** を使ったバックエンド連携が必要です。
実装を進める場合は、ダッシュボードの作成者（suwa）または担当者に確認してください。

## 対応媒体

- Meta（Facebook/Instagram広告）
- Google 広告
- Amazon 広告
- Yahoo! 広告
- LINE 広告
- 楽天広告
- アフィリエイト
